## Projects

### [Paper Research Assistant](https://github.com/parhamKIY/LLM)

A bilingual assistant for searching scientific papers and asking questions about their contents, with document retrieval, tool calling, and voice input.

<sub>RAG · FAISS · Sentence Transformers · Whisper</sub>

### [Image CAPTCHA Solver](https://github.com/parhamKIY/captcha-braker-)

An image-based CAPTCHA project combining YOLO classification with Selenium, including class balancing, augmentation, and test-time augmentation.

<sub>Computer Vision · YOLO · PyTorch · Selenium</sub>

### [Network Anomaly Detection](https://github.com/parhamKIY/anomaly-detection-project)

Network anomaly detection with classical and deep models, plus black-box evasion experiments using a surrogate model. Includes LLM-assisted analysis of detected anomalies.

<sub>Isolation Forest · Autoencoders · 1D CNN · Adversarial ML</sub>

### [IoT Trust Assessment](https://github.com/parhamKIY/Providing-a-Method-to-Improve-the-Level-of-Trust-in-IOT-Networks-Using-Deep-Learning-Structure)

An implementation of our published work combining SMART trust scoring with LSTM-based analysis of behavioral changes in IoT networks.

<sub>Deep Learning · LSTM · Trust Modeling · IoT</sub>

### [Deep Q-Learning Agent](https://github.com/parhamKIY/DQN)

A PyTorch DQN agent for a custom grid-world environment, with experience replay, target-network updates, and Pygame visualization.

<sub>Reinforcement Learning · DQN · PyTorch · Pygame</sub>

### [Credit Limit Prediction](https://github.com/parhamKIY/DATA_MINING)

Data preprocessing, feature engineering, and comparison of regression models and an artificial neural network for credit-limit prediction.

<sub>Data Mining · Regression · Neural Networks · Feature Engineering</sub>

### [Adult Income Data Analysis](https://github.com/parhamKIY/ML-project)

Exploratory analysis and visualizations of demographic and income data from the Adult dataset.

<sub>Data Analysis · pandas · seaborn · Matplotlib</sub>

### [Smart Parking Management](https://github.com/parhamKIY/SmartParkingManagementSystem)

A team IoT course project with a web interface for managing a smart parking system.

<sub>IoT · Web Development · Team Project</sub>

### [Proxy Server](https://github.com/parhamKIY/Proxy-simulation)

A threaded Python proxy with HTTP forwarding, HTTPS tunneling, caching, host filtering, request logging, and rate limiting.

<sub>Computer Networks · Python Sockets · HTTP / HTTPS · Multithreading</sub>

### [Reliable Transport over UDP](https://github.com/parhamKIY/TCP-connection-simulation)

A computer-networks project implementing reliable data transfer on top of UDP.

<sub>Computer Networks · Transport Protocols · UDP · Python</sub>

### [Neural Choice Decoding](https://github.com/parhamKIY/neuroconnect-project)

Predicting an animal's left or right choice from IBL neural population recordings, with population-level and brain-region analyses.

<sub>Computational Neuroscience · Neural Data · Logistic Regression</sub>

### [Gene Selection for Cancer Classification](https://github.com/parhamKIY/A-Feature-Selection-Method-on-Gene-Expression-Microarray-Data-for-Cancer-Classification-Abstract)

Python implementation of our published gene-selection method, combining variance filtering, extremely randomized trees, whale optimization, and KNN classification.

<sub>Feature Selection · Gene Expression · Optimization · KNN</sub>

### [Visual DSD Rebooted](https://github.com/parhamKIY/Visual-DSD-rebooted)

A modern workspace around the original Visual DSD core for molecular modeling, reaction-network visualization, simulation, and guided scientific activities.

<sub>Scientific Software · F# / .NET · Simulation · Molecular Computing</sub>

### [Simulated Annealing](https://github.com/parhamKIY/Simulated-annealing)

Simulated annealing for the DNA center-string problem, with hill-climbing and brute-force implementations for comparison.

<sub>Optimization · Local Search · NumPy · Jupyter</sub>

### [Grammar Simplification](https://github.com/parhamKIY/theory-of-languages-2)

A formal-languages course project for simplifying grammar rules and transforming longer productions into binary rules.

<sub>Formal Languages · Grammars · Python</sub>
